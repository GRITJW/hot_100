    00 知识地图¶

    整个知识体系的总览。先看完这一页，再去具体板块。

    一、整体架构¶

    13 个板块按"基础 → 工程 → 方向"三层递进：

    层 板块 性质
    稳定底座 00 知识地图 / 01 计算机系统基础 / 02 数学统计优化 / 03 编程与工程能力 / 04 数据结构与算法 一辈子不变的能力，对所有上层都有用
    通用 ML/DL 05 机器学习基础 / 06 深度学习与 PyTorch AI 工程师的"通识课"
    技术方向 07 推荐搜索广告 / 08 大模型 / 09 多模态 / 10 Agent 与 AI 应用工程 4 个可独立深耕的方向，相互可交叉（如生成式推荐、多模态推荐、Agent for Search）
    产出材料 11 项目实验与面试 / 12 论文精读 复盘、面试、阅读积累，跨方向沉淀

    设计原则：基础是底盘（不变），方向是模块（可替换/扩展）。新方向插入时，只动方向层，底座不动。

    08 大模型 ⭐ 重点¶

    定位：从一个 token 序列出发，怎么训出 GPT/Claude/Qwen 这样的基础模型，再变成服务。

    整条主线：Tokenizer → 架构 → 预训练 → 后训练 → 微调 → 推理 → RAG → 评测

    子目录 是什么 关键概念
    01_Tokenizer 与文本建模 文本怎么变成模型能吃的 token 序列 BPE / WordPiece / SentencePiece、词表、特殊 token、Chat Template、CLM/MLM/PrefixLM
    02_Transformer 架构 大模型骨架的"零件清单" Self-Attention 实现、位置编码（绝对/相对/RoPE/ALiBi）、归一化（LayerNorm/RMSNorm，Pre/Post-Norm）、激活（GELU/SwiGLU）、MoE 混合专家
    03_预训练 怎么从零训一个基座模型 数据来源/清洗/配比/去重、目标函数、Scaling Law（参数×数据×算力的最优配比）、训练系统（DP/TP/PP/ZeRO/FSDP 分布式策略）
    04_后训练-偏好对齐 让"会续写的基座"变成"会聊天、对齐人类偏好的助手" SFT（监督微调，指令数据）、Reward Model（奖励模型）、RLHF（基于奖励模型用 PPO 训练）、DPO（直接偏好优化，省掉显式奖励模型）、GRPO（组相对策略优化，DeepSeek-R1 用）
    05_高效微调 全参微调显存吃不消时的方案 LoRA、QLoRA、Adapter、Prefix-Tuning、Prompt-Tuning、PEFT 工具链
    06_推理与部署 训完的模型怎么在线上跑得又快又便宜 KV Cache、量化（INT8/INT4，GPTQ/AWQ）、Speculative Decoding、推理引擎（vLLM/TGI/SGLang）、并发吞吐优化
    07_RAG 给模型外挂"知识库"，避免幻觉、获取最新信息 检索（BM25 稀疏 / 向量稠密 / 混合）、向量库（Milvus/Faiss/pgvector）、rerank（重排）、chunk 策略、prompt 上下文构造、RAG 评测（忠实性、相关性、答案准确性）
    08_评测与安全 大模型靠什么衡量好坏，怎么避免翻车 Benchmark（MMLU/GSM8K/HumanEval/Arena）、LLM-as-a-Judge、幻觉检测、越狱防御、偏见/隐私、安全对齐

    DPO/GRPO 和 RLHF 的关系：三者都是"后训练偏好对齐"这个目标下的不同算法路径。RLHF 是经典 PPO 路线（要训奖励模型，再用 PPO 做策略优化）；DPO 直接用偏好数据优化，跳过奖励模型；GRPO 是 PPO 的简化变体，用 group 内的相对得分代替 critic。所以它们都在 04_后训练-偏好对齐 下，并列作为算法选项。

    09 多模态 ⭐ 重点¶

    定位：让模型同时理解或生成图像、音频、视频等多种模态。

    子目录 是什么 代表内容
    01_模态编码 不同模态如何变成向量送进模型 图像：ViT、ConvNeXt；音频：Whisper、Wav2Vec；视频：VideoMAE、TimeSformer
    02_跨模态对齐 让不同模态的语义在同一个空间里能比较 CLIP（图文对比学习，多模态最重要的奠基工作）、BLIP、ALIGN、SigLIP
    03_VLM（视觉语言模型） 把视觉编码器 + LLM 拼起来，让 LLM 能"看图说话" 投影层方案：MLP / Q-Former / Resampler；代表：LLaVA、MiniGPT、MiniCPM-V、Qwen-VL、GPT-4V
    04_多模态指令微调 让 VLM 听懂"看图回答这个问题"这类指令 多模态指令数据构造（图文问答、图表理解、OCR、视觉推理）、视觉 SFT 流程
    05_多模态生成 反过来：从文本生成图/视频/音频 Diffusion 基础（DDPM/DDIM/Flow Matching）、文生图（Stable Diffusion/SDXL/Flux）、文生视频（Sora/Runway/Pika）、ControlNet、LoRA 微调
    06_多模态推荐与内容理解 把多模态用到工业场景 短视频内容理解（封面 OCR、字幕 ASR、动作识别）、多模态特征融合、多模态召回与排序

    理解多模态的关键概念链：编码（每个模态各自变成向量）→ 对齐（不同模态的向量映射到同一语义空间，CLIP 是标杆）→ 融合（VLM 把视觉向量塞进 LLM 上下文）→ 生成（反过来，从文本生成其他模态）。

    10 Agent 与 AI 应用工程 ⭐ 重点¶

    定位：把 LLM 当作"可以调用工具、有记忆、能多步执行"的智能体，构建上层应用。这是应用系统层，依赖大模型但独立于大模型原理。

    子目录 是什么 关键概念
    01_Prompt 与工具调用 让 LLM 学会"调用外部工具"的最基础形态 Prompt Engineering（CoT/Few-shot/ReAct）、Function Calling / Tool Calling 协议（OpenAI/Anthropic 规范）、结构化输出（JSON Schema、guided decoding）
    02_Agent 编排 把 LLM + 工具组合成可执行的多步流程 单 Agent：Plan-Execute、ReAct 循环；多 Agent：协作、handoff（OpenAI Agents SDK / Swarm）；Workflow Engine（LangGraph、CrewAI、AutoGen）
    03_记忆与状态 Agent 的"记忆"机制：短期对话、长期知识、运行时变量 Short-term Memory（对话历史、context window 管理）、Long-term Memory（向量记忆、Memory Bank、MemGPT）、State Management（会话状态、变量传递）、Reflection（自我反思与修正）
    04_MCP 与工具生态 标准化的"AI 工具"协议和生态 MCP（Model Context Protocol，Anthropic 推出的工具标准协议）、工具市场（npm/pypi 风格）、权限边界与沙箱、安全；用户收集的 openclaw 工具笔记也在此
    05_可观测与评测 Agent 跑起来怎么 debug、监控、评估 Tracing（每一步可视化，LangSmith/Langfuse）、Guardrails（输入输出守卫：违规/PII/安全）、Human-in-the-Loop（人工干预）、Agent 评测（成功率/效率/安全性）

    Agent 不属于"大模型"的原因：大模型回答的是"模型本身的能力如何训出来"；Agent 回答的是"模型已经训好了，怎么把它包装成能完成真实任务的应用"。前者是模型科学，后者是系统工程。

    三、推荐学习路径¶

    不同背景对应不同切入点：

    • 完全新手：01 → 03 → 04 → 05 → 06，先打底再谈方向
    • 已有 ML 基础，转大模型：直接 06_Transformer → 08 大模型主线（按 01 → 08 顺序）→ 10 Agent
    • 已有 ML 基础，做推荐：05 经典模型 → 07 推荐搜索广告 → 看 04_序列推荐与生成式推荐 与大模型交叉
    • 做多模态：08 大模型主线 → 09 多模态（02 对齐 → 03 VLM → 05 生成）
    • 做 Agent 应用：08 大模型 04_后训练 + 06_推理 部分概念 → 10 Agent 全系列
